# 음악 작업 화면 개선

## 기준과 참고 자료

기존 band2sheet와 AirChoir의 기능과 라이브러리를 유지하며, 합성 입력으로 실행한 화면과 공식 공개 문서·이미지를 기준으로 정보 구조와 조작 상태를 다듬습니다. 아래 관찰은 공개 자료에 관한 것이며 해당 서비스에 로그인하거나 최신 데스크톱 바이너리를 실행해 검증한 결과가 아닙니다. 타사 상표나 화면을 복제하지 않습니다.

## 기존 화면에서 확인한 문제

- band2sheet: 데스크톱 1440×1000에서 악보가 화면 위쪽 356px 아래부터 시작했습니다. 제목·키 변경·보기·악기 도구의 여백과 높이가 누적됐으며, 모바일에서는 악보가 첫 화면 밖으로 밀렸습니다. 초기 입력 화면은 분석 옵션이 시작 버튼보다 먼저 긴 공간을 차지했습니다.
- AirChoir: 같은 데스크톱 크기에서 소리 입력은 약 1016px, 조성 선택은 약 1203px 위치에 있어 첫 화면 밖에 있었습니다. 긴 손동작 설명이 핵심 조작보다 먼저 배치됐고, 빈 무대에서 다음 동작을 찾기 어려웠습니다.
- 키보드 파일 선택·작업 선택, 저장하지 않은 편집 후 이동 취소, 오류 후 재조회, 녹음 취소·시작 화면 복귀처럼 반복 작업에 필요한 경로를 함께 점검합니다.

## 구현 범위

band2sheet는 어두운 도구 영역과 흰 악보 작업면을 구분하고 기존 조옮김·코드 편집·악기별 편집·다운로드를 유지합니다. AirChoir는 기존 공간 오브를 유지하며 소리 입력·화음·녹음·루프 상태를 가까운 위치에 모으고 긴 안내를 펼침 영역으로 옮깁니다. 기존 엔진 밖의 동기화·오버더빙·협업 기능을 표시하지 않습니다.

새 모델, 외부 API, 실제 마이크·카메라 권한은 검증에 사용하지 않습니다. UI 검증 결과는 실제 음원의 분리·채보·화음 품질 평가와 구분합니다.

## 구현 결과

band2sheet는 입력과 시작 동작을 앞에 두고 세부 분석 옵션을 펼침 영역으로 옮겼습니다. 프로젝트 목록·조옮김·보기·악기 선택은 작은 도구 영역으로 정리하고 흰 악보의 너비를 넓혔습니다. 화면의 중복 악보 제목을 숨겨 공간을 확보했으며 다운로드 MusicXML의 원래 제목은 유지합니다. 파일 선택과 프로젝트 선택은 키보드로 접근할 수 있고, 실패 상태에는 원인과 재시도 동작을 제공합니다.

AirChoir는 녹음·완료·취소 버튼과 실제 루프의 선택·음소거·삭제·배치 조작을 추가했습니다. 이 버튼과 기존 손동작은 같은 녹음 상태 전이를 사용합니다. 녹음 상태는 색과 문구로 함께 표시하고 입력·박자·화음을 작업 무대 주변에 모았습니다. 시작 취소와 세션 종료·복귀도 가능하며 세션 종료 시 메모리의 녹음은 비웁니다. 표준 doctype·viewport와 로컬 시스템 글꼴을 적용했습니다.

| 측정 대상 | 개선 전 | 개선 후 |
|---|---:|---:|
| band2sheet 데스크톱 악보 시작 위치 | 356px | 257px |
| band2sheet 데스크톱 악보 너비 | 1122px | 1172px |
| band2sheet 모바일 악보 시작 위치 | 797px | 445px |
| AirChoir 데스크톱 입력 조작 위치 | 1016px | 144px |
| AirChoir 모바일 BPM 조작 위치 | 1320px | 149px |

위 수치는 동일한 합성 입력과 데스크톱 1440×1000·모바일 390×844 뷰포트에서 얻은 화면 좌표입니다. band2sheet 모바일 주요 버튼은 최종 44px 높이로 맞췄으며 첫 화면에서 악보 약 334px가 보입니다. AirChoir 대표 화면의 오브 세 개는 합성 데모를 실제 AudioWorklet으로 녹음해 만든 루프입니다.

## 상태 처리와 검증

XML·OSMD 렌더 요청은 작업과 악기·요청별로 분리하여 늦은 응답이 현재 화면을 바꾸지 않도록 했습니다. 조옮김·저장 대기 중 새 음표 수정과 undo, 코드 저장으로 화면을 갱신할 때 미저장 음표를 보존합니다. 팝업의 Escape는 원래 코드로 포커스를 돌려주고, 팝업 밖 가사·선택 상자 클릭은 그 조작의 포커스를 유지합니다. 독립 코드 검토에서 발견한 편집 보존·포커스 문제 네 건을 수정했습니다.

자동 검사 208개 통과·선택 의존성 관련 2개 skip, 실제 band2sheet 브라우저 체크리스트 16개와 AirChoir의 pointer·Phase 0·controls 검사를 확인했습니다. 전체 범위와 모의 입력의 한계는 [VALIDATION.md](VALIDATION.md)에 기록했습니다. 전후 화면과 상세 로그는 제품 저장소 밖에 보관하며, 대표 PNG 두 장을 별도 전달합니다.
