# AirChoir

> 허밍 한 번이면, 내가 합창단.

마이크에 노래하면 내 목소리로 화음이 쌓이고, 카메라 앞에서 손을 움직여 합창단을 지휘하는 브라우저 앱입니다.
기획은 [PLAN.md](PLAN.md), 화음 엔진 비교는 [phase0/](phase0/README.md)에 있습니다.

지금은 **Phase 1(합창단 모드 + 카메라 UI)**까지 구현되어 있습니다.

## 실행하기

카메라와 마이크를 쓰려면 내 컴퓨터에서 실행합니다. (`localhost`는 카메라·마이크 권한이 허용됩니다)

```bash
cd air-choir
python3 -m http.server 8000
# Chrome에서 http://localhost:8000 열기
```

설치할 패키지는 없습니다. 손 인식(MediaPipe)은 처음 시작할 때 인터넷에서 받아 옵니다 (약 20MB, 이후 브라우저 캐시).

시작 화면의 버튼 세 개:

| 버튼 | 소리 | 손 |
|---|---|---|
| 카메라·마이크로 시작 | 내 목소리 (이어폰 필수) | 카메라 |
| 데모 노래로 시작 | 합성 목소리 "작은 별" | 카메라 |
| 카메라 없이 마우스로 해 보기 | 데모 노래 | 마우스 위치 + 키보드 `0`~`5` |

## 손동작

| 손동작 | 효과 |
|---|---|
| 손이 안 보임 | 화음 없음 (내 목소리만) |
| 손가락 1개 | 3도 위 |
| 손가락 2개 | 3도 + 5도 위 |
| 손가락 3개 | 3·5도 + 옥타브 아래 베이스 |
| 손가락 4~5개 | 풀 합창 (4성부) |
| 주먹 (엄지만 펴도 마찬가지) | 즉시 정지 |
| 손 높이 | 합창단 음량 |
| 손 좌우 | 왼쪽: 어둡고 울림 많게 / 오른쪽: 밝고 선명하게 |

- 손이 둘 보이면 카메라에 더 가까운(크게 보이는) 손을 씁니다.
- 손가락 개수는 같은 값이 0.09초 이상 이어져야 바뀌고, 손이 0.25초 안에 다시 보이면 화음이 끊기지 않습니다.
- 화음은 고른 키의 스케일 안에서 계산되어 불협화음이 나지 않습니다.
- 화음 엔진은 기본 PSOLA이고, `Q` `W` `E`로 그레인 / PSOLA / 합성을 바꿀 수 있습니다. Phase 0 평가 결과가 나오면 기본값을 정합니다.

```
┌─────────────────────────────────────────────┬──────────────┐
│ [지금 부르는 음 A4] [합창단 C5 E5] [2개 · 3도+5도]    합창단 음량 │ 손동작 안내     │
│                                         ▮ │ (지금 동작 강조) │
│          (C5)          (E5)   ← 합창단 오브   ▮ │ 소리 입력 · 볼륨 │
│                 ( 2 )         ← 손가락 링     ▮ │ 키 · 엔진       │

│      어둡게 · 울림 ━━━━━●━━━━ 밝게 · 선명       │              │
└─────────────────────────────────────────────┴──────────────┘
```

## 구조

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 화면과 스타일 |
| `src/app.js` | 시작 흐름, 입력 전환, HUD, 음정 그래프 |
| `src/gestures.js` | 손 랜드마크 → 손가락 개수·주먹·높이·좌우 (순수 로직) |
| `src/hands.js` | 카메라 + MediaPipe HandLandmarker |
| `src/audio.js` | 오디오 그래프 (하모나이저 → 밝기 필터 → 합창단 음량 → 리버브) |
| `src/stage.js` | 카메라 위 그리기: 손 뼈대, 링, 오브, 게이지 |
| `core/dsp.js` | 음정 검출, 화음 계산, 화음 엔진 3종 (Phase 0에서 검증) |
| `core/worklet.js` | 오디오 스레드에서 하모나이저 실행 |
| `phase0/` | 화음 엔진 비교 테스트 벤치 |

내 목소리(모니터)는 오디오 처리를 거치지 않고 바로 나가서 추가 지연이 없습니다.

## 테스트

```bash
cd air-choir
npm test        # 단위 테스트: 오디오 처리 7개 + 손동작 6개 (Node 22)
npm run check   # 헤드리스 Chromium으로 앱과 Phase 0 화면을 끝까지 실행 (playwright 필요)
```

- 손동작 판정은 MediaPipe 공식 샘플 사진 9장(주먹, 손가락 1개, V, 엄지척, 편 손 등)에서 뽑은 **실제 랜드마크**(`test/fixtures/hands.json`)로 검증합니다. 사진 속 손 11개가 모두 맞게 판정됩니다.
- `app.check.mjs`는 가짜 카메라에 손 사진을 순서대로 비추고(1개 → V → 편 손 → 주먹), 화면이 손동작과 화음을 따라가는지 확인합니다. 처음 실행할 때 MediaPipe 패키지와 사진을 `test/.cache`에 받습니다.
- 주소 끝에 `#cpu`를 붙이면 GPU 대신 CPU로 손을 인식합니다 (GPU 가속이 없는 환경용).
