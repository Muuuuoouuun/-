# AirChoir Phase 0 · 화음 엔진 비교 테스트

[기획서](../PLAN.md)의 Phase 0입니다. **내 목소리를 실시간으로 음정 이동시켜 화음을 만들 때, 음질과 지연이 쓸 만한지** 검증합니다.
손 추적은 아직 없고, 키보드 `0`~`4`가 손가락 개수를 대신합니다.

## 실행하기

마이크를 쓰려면 내 컴퓨터에서 실행해야 합니다. (`localhost`는 마이크 권한이 허용됩니다)

```bash
cd air-choir/phase0
python3 -m http.server 8000
# 브라우저(Chrome 권장)에서 http://localhost:8000 열기
```

설치할 패키지는 없습니다. 외부 라이브러리 없이 Web Audio + AudioWorklet만 씁니다.

## 화면에서 할 수 있는 것

| 입력 | 용도 |
|---|---|
| ▶ 데모 멜로디 | 합성 목소리로 부른 "작은 별". 마이크 없이 엔진 소리를 비교 |
| 🎤 마이크 | **실제 테스트.** 이어폰 필수. 실시간 지연을 체감 |
| 📂 녹음 파일 열기 | 휴대폰으로 녹음한 내 노래를 넣어서 비교 |

| 엔진 | 원리 | 예상 |
|---|---|---|
| A · 그레인 (`Q`) | 지연선 두 개를 교차 페이드. Tone.js `PitchShift`와 같은 방식 | 단순하지만 울림이 생기고, 음이 높아질수록 다람쥐 목소리가 됨 |
| B · PSOLA (`W`) | 목소리 한 주기 단위로 잘라 간격을 바꿔 붙임 | 모음의 음색이 덜 변함. 숨소리나 자음에는 약함 |
| C · 합성 보이스 (`E`) | 부른 음을 따라 "아~" 소리를 새로 합성 | 깨끗하지만 내 목소리가 아님. 대체 경로 |

- 숫자 `0`~`4`: 화음 구성 (없음 / 3도 위 / 3·5도 위 / +베이스 / 풀 합창)
- `R`: 녹음 시작·끝. 엔진별로 녹음해서 바로 다시 들어 볼 수 있습니다
- 그래프: 최근 6초 동안 내가 부른 음(흰 선)과 화음(색 선)
- 지연 패널: 입력 장치 + 엔진 + 브라우저 처리 단위 + 출력 장치를 더한 예상값

## 평가 방법

1. 이어폰을 끼고 마이크 모드에서 "아~"를 길게, 그다음 아는 노래를 한 소절 부릅니다.
2. `Q` `W` `E`로 엔진을 바꿔 가며 같은 소절을 부르고 `R`로 녹음해 둡니다.
3. 아래 표를 채웁니다.

| 항목 | A 그레인 | B PSOLA | C 합성 |
|---|---|---|---|
| 화면의 예상 총 지연 (ms) | | | |
| 체감 지연 (거슬림 1~5) | | | |
| 내 목소리처럼 들림 (1~5) | | | |
| 화음 음정 정확도 (1~5) | | | |
| 빠른 멜로디를 따라옴 (1~5) | | | |

**통과 기준** (기획서 Phase 0): 총 지연 100ms 이하, 이어폰으로 들을 만한 음질.
통과한 엔진이 Phase 1(합창단 모드)의 기본 엔진이 됩니다. 셋 다 미달이면 위상 보코더 방식을 추가로 시험합니다.

## 개발자용 확인

```bash
cd air-choir/phase0
npm test                       # DSP 단위 테스트 (Node 22)
node test/browser.check.mjs    # 헤드리스 Chromium으로 화면 동작 확인 (playwright 필요)
```

자동 테스트로 확인한 것 (합성 음원 기준):
- 음정 검출: 82~880Hz에서 오차 ±10 cent 이내
- 엔진 A·B: 장3도 위, 완전5도 위, 옥타브 아래로 옮긴 결과가 목표 음 ±20 cent 이내
- 엔진 3종 모두 E4를 부르면 3도 위 G4를 만듦
- 4성부 화음 처리 시간: 실시간 대비 약 4~5% (Node 기준)
- 엔진 자체 지연: A는 창 길이의 절반(기본 20ms), B는 약 21ms, C는 0ms. 음정 추적 지연은 약 32ms

진짜 목소리(숨소리, 비브라토, 자음)에서의 품질은 자동 테스트로 판단할 수 없어서, 위 평가표로 직접 들어 보고 판단합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `dsp.js` | 음정 검출(YIN), 스케일·화음 계산, 엔진 3종, 하모나이저, 데모 음원 |
| `worklet.js` | 오디오 스레드에서 하모나이저 실행 |
| `app.js` | 화면, 입력 전환, 그래프, 지연 계산, 녹음 |
| `index.html` | 화면 구성과 스타일 |
| `test/` | DSP 단위 테스트, 브라우저 동작 확인 |
